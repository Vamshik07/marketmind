🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

Email not received?
  → Check .env: GMAIL_ADDRESS, GMAIL_APP_PASSWORD
  → Verify Gmail 2-Step Verification enabled
  → Check spam folder
  → Review Flask console for errors

Login fails?
  → Verify email is verified (check inbox)
  → Confirm password is correct
  → Clear browser cookies
  → Check database exists: marketmind.db

History not showing?
  → Verify logged in
  → Check user_id in database
  → Try different date filters

Port 5000 in use?
  → Edit app.py: app.run(port=5001)
  → Or kill process: lsof -i :5000

Module not found?
  → pip install -r requirements.txt --force-reinstall

📊 DATABASE TABLES
═══════════════════════════════════════════════════════════════════════════════════

users
  id              INTEGER PRIMARY KEY
  name            TEXT NOT NULL
  email           TEXT UNIQUE NOT NULL
  password_hash   TEXT NOT NULL
  is_verified     BOOLEAN DEFAULT 0
  created_at      DATETIME
  updated_at      DATETIME

user_history
  id              INTEGER PRIMARY KEY
  user_id         INTEGER (FK → users.id)
  page_url        TEXT NOT NULL
  page_title      TEXT
  action_type     TEXT NOT NULL
  metadata        TEXT (JSON)
  timestamp       DATETIME
  ip_address      TEXT
  user_agent      TEXT
